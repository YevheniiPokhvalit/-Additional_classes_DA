# 🐍 Урок 1. Вступ до програмування. Перша програма Python



## 1. Програмування навколо нас

Програмування — це створення точних інструкцій, за якими комп'ютер виконує дії. Програми працюють у смартфонах, браузерах, іграх, банківських застосунках і роботах.

Уяви, що ти пояснюєш роботу кавомашині:

1. Постав чашку.
2. Перевір, чи є вода.
3. Нагрій воду.
4. Приготуй каву.
5. Повідом, що напій готовий.

Це приклад **алгоритму** — послідовності зрозумілих кроків для досягнення мети. У реальній програмі кожен крок має бути настільки точним, щоб виконавець не мусив здогадуватися, що робити.

**Програма** — алгоритм, записаний мовою, яку можна виконати на комп'ютері (безпосередньо або через спеціальне програмне забезпечення).

**Мова програмування** — система правил для запису таких інструкцій. **Python** — одна з мов програмування; її синтаксис зручний для першого знайомства з кодом.

### Як працює наша перша програма

```text
Ми пишемо код у файлі .py
          ↓
Запускаємо його в Thonny
          ↓
Інтерпретатор Python виконує команди
          ↓
Бачимо результат у вікні Shell
```

> **Запам'ятай:** написати код і запустити його — різні дії. Файл зберігає інструкції, а **Shell** показує результат виконання й може приймати окремі команди.

### Перевір себе

1. Що буде алгоритмом у твоєму повсякденному житті?
2. Чому комп'ютеру потрібні точні інструкції?
3. Чим код програми відрізняється від результату її запуску?

## 2. Підготовка робочого середовища Thonny

**Thonny** — навчальне середовище для програмування Python: у ньому можна писати, зберігати, запускати й налагоджувати код.

### 2.1. Установлення

1. Перейди на офіційний сайт **https://thonny.org/**.
2. Обери інсталятор для своєї операційної системи (Windows, macOS або Linux). Назви кнопок і вигляд сайту можуть оновлюватися.
3. Завантаж програму та виконай кроки встановлення.
4. Запусти **Thonny**. Для стандартного навчального встановлення зазвичай достатньо Python, що постачається разом із Thonny. Якщо середовище пропонує обрати інтерпретатор, обери локальний Python 3.

> **Безпека:** завантажуй установлювач із офіційного сайту; якщо комп'ютер шкільний і встановлення заборонене, звернися до викладача. Не потрібно змінювати системні параметри без дозволу.

### 2.2. Основні елементи вікна

| Частина | Для чого потрібна |
|---|---|
| **Редактор (Editor)** | Тут пишемо текст програми у файлі `.py`. |
| **Shell** | Тут бачимо вивід програми й повідомлення про помилки. |
| **Run / Запуск** | Запускає програму; типовий ярлик — **F5**. На окремих ноутбуках може знадобитися `Fn + F5`. |
| **File → Save / Зберегти** | Записує файл на диск. |

### 2.3. Створення першого файлу

1. Відкрий Thonny.
2. Обери **File → New** (або створення нового файлу).
3. У редакторі введи:

```python
print("Привіт, світе!")
```

4. Обери **File → Save As...** або **Save**, за потреби створи папку `Python_11`, збережи файл під назвою `lesson01_hello.py`.
5. Натисни **Run → Run current script** або **F5**.
6. У Shell знайди результат:

```text
Привіт, світе!
```

Після запуску середовище може також показувати службові рядки й запрошення `>>>` — це нормально. Шукай саме текст, який вивела твоя програма.

**Що робити, якщо результату немає?** Переконайся, що код введено в редакторі; файл запущений; у нижній області відкритий Shell; немає повідомлення про помилку.

## 3. Перша команда: `print()`

`print()` — вбудована функція Python, яка показує передані їй значення у виводі програми. Сьогодні ми використовуємо її для текстових повідомлень.

```python
print("Мене звати Оля")
```

**Розберімо по частинах:**

| Фрагмент | Значення |
|---|---|
| `print` | Назва функції для виведення. Її пишемо **маленькими англійськими літерами**. |
| `(` | Відкриває дужки виклику функції. |
| `"Мене звати Оля"` | Рядок — текст у лапках, який хочемо показати. |
| `)` | Закриває виклик функції. |

**Результат:**

```text
Мене звати Оля
```

### 3.1. Один виклик — одне повідомлення

```python
print("Я вивчаю Python")
```

```text
Я вивчаю Python
```

Python читає команду `print`, знаходить текст між лапками і виводить його. **Лапки служать для позначення тексту в коді; у результаті вони не з'являються.**

### 3.2. Кілька команд — кілька рядків

```python
print("Перший рядок")
print("Другий рядок")
print("Третій рядок")
```

```text
Перший рядок
Другий рядок
Третій рядок
```

Кожен виклик `print()` за замовчуванням завершує виведення переходом на новий рядок. Команди виконуються **зверху вниз**.

### 3.3. Подвійні й одинарні лапки

У Python можна використовувати подвійні **або** одинарні лапки для одного текстового рядка:

```python
print("Привіт!")
print('Вітаю!')
```

Обидва варіанти правильні. Важливо, щоб лапки з обох боків **узгоджувалися**.

```python
print("Привіт!')
```

Цей приклад **помилковий**: рядок відкритий подвійними лапками, але закритий одинарними.

### 3.4. `print()` може виводити декілька фрагментів

```python
print("Мій улюблений предмет —", "інформатика")
```

```text
Мій улюблений предмет — інформатика
```

**Пояснення:** між двома текстовими фрагментами стоїть кома `,`. `print()` виведе їх поспіль і **за замовчуванням поставить між ними пробіл**. Це не те саме, що кома всередині лапок.

### 3.5. Порожній рядок

```python
print("Початок")
print()
print("Кінець")
```

```text
Початок

Кінець
```

`print()` без тексту створює порожній рядок. Це корисно, коли хочемо відділити частини повідомлення.

### 3.6. Простий текстовий малюнок

```python
print("  /\\_/\\")
print(" ( o.o )")
print("  > ^ <")
```

```text
  /\_/\
 ( o.o )
  > ^ <
```

Тут кожен рядок коду виводить окремий рядок малюнка. У першому рядку `\\` у коді означає один символ зворотної косої риски у виводі. Це **спеціальна послідовність** для запису такого символу всередині тексту; детальніше спеціальні символи вивчатимемо на уроці 5.

> **Мініпідсумок:** код усередині `print()` — це інструкція; те, що ти бачиш в Shell, — її результат.

## 4. Коментарі — нотатки в програмі

Іноді потрібно пояснити, для чого написаний певний рядок. Для цього використовують **коментарі**.

У Python символ `#` поза лапками починає коментар до кінця рядка. Інтерпретатор не виконує текст такого коментаря як команду.

```python
# Програма вітає користувача
print("Ласкаво просимо!")
```

Результат:

```text
Ласкаво просимо!
```

Текст коментаря не виводиться.

### Коментар після команди

```python
print("Готово!")  # Повідомлення про завершення
```

Результат:

```text
Готово!
```

### Символ `#` усередині лапок — не коментар

```python
print("#Python")
```

Результат:

```text
#Python
```

**Чому так?** Python бачить `#` **всередині текстового рядка** — це частина тексту, а не позначка коментаря.

**Корисне правило:** коментар має пояснювати **навіщо** потрібна частина коду, а не просто дублювати очевидну команду.

## 5. Правила написання коду та типові помилки

Python уважний до синтаксису. Він не здогадається автоматично, що ти забув лапки або неправильно написав назву функції.

| Помилковий код | Причина | Правильний варіант |
|---|---|---|
| `Print("Привіт")` | Python розрізняє великі й малі літери. | `print("Привіт")` |
| `print(Привіт)` | Текст без лапок розглядається не як рядок. | `print("Привіт")` |
| `print("Привіт"` | Не вистачає закривальної дужки. | `print("Привіт")` |
| `print("Привіт)` | Не закрито текстовий рядок. | `print("Привіт")` |
| `pritn("Привіт")` | Помилка в назві функції. | `print("Привіт")` |

### Як виправляти помилки — алгоритм із чотирьох кроків

1. **Прочитай повідомлення** в Shell, особливо останній рядок і номер рядка коду, якщо він зазначений.
2. **Знайди фрагмент**, на який вказує Python. Іноді фактична помилка є трохи раніше.
3. **Перевір символи:** латинське `print`, парні дужки `()`, парні лапки `""` або `''`.
4. **Виправ і запусти повторно**. Не змінюй одразу все — так легше побачити причину.

### Важлива різниця

- **Синтаксична помилка** — запис порушує правила мови, і програма не може правильно виконатися.
- **Помилка під час виконання** — запис може бути формально правильним, але під час запуску виникає проблема, наприклад невідома назва `pritn`.
- **Логічна помилка** — програма виконується, але результат не відповідає задуму, наприклад надруковано `Понеділок` замість `Вівторок`.

## 6. Повністю розібраний приклад: «Моя візитівка»

**Завдання:** зробити програму, яка виводить невелику візитівку учня.

```python
# Моя перша програма-візитівка
print("========================")
print("       ПРИВІТ!")
print("Мене звати Максим")
print("Я навчаюся в 11 класі")
print("Мені цікаве програмування")
print("========================")
```

**Очікуваний результат:**

```text
========================
       ПРИВІТ!
Мене звати Максим
Я навчаюся в 11 класі
Мені цікаве програмування
========================
```

### Розбір усіх рядків

1. `# Моя перша програма-візитівка` — пояснення в коді. На екран **не виводиться**.
2. `print("========================")` — друкує лінію з символів `=`.
3. `print("       ПРИВІТ!")` — друкує привітання. Пробіли **всередині лапок** зберігаються.
4. `print("Мене звати Максим")` — виводить ім'я (у своїй програмі заміни його).
5. `print("Я навчаюся в 11 класі")` — виводить навчальний клас.
6. `print("Мені цікаве програмування")` — додає інтерес учня.
7. `print("========================")` — закриває рамку.

**Що можна змінити без нових знань:** текст повідомлень, кількість рядків, кількість символів `=`, пробіли всередині лапок. **Не змінюй** написання `print`, якщо хочеш, щоб команда працювала.

### Самостійний експеримент (2 хвилини)

Замінюй по одному елементу та дивись на зміну виводу:

1. Заміни ім'я на своє.
2. Додай ще один рядок через `print()`.
3. Додай порожній рядок за допомогою `print()`.
4. Напиши коментар над новим рядком.

## 7. Мінісловник уроку

| Поняття | Простими словами |
|---|---|
| Алгоритм | Чіткий порядок дій для досягнення результату. |
| Програма | Запис інструкцій для виконання комп'ютером. |

| Код | Текст програми. |
