### Завдання 2. «Три факти» — 3 хв

Створи `practice01_b.py`. Напиши програму, яка виведе:


## 🔵 Рівень 2. Середній: створюємо самостійно

### Завдання 3. «Афіша події» — 6 хв

Створи `practice01_poster.py`. Напиши програму, яка показує афішу шкільної події. Використай:

- **не менше шести** викликів `print()`;
- назву події, місце, дату (вигадану або погоджену), короткий заклик;
- два рядки-розділювачі з `=` або `-`;
- принаймні **один порожній рядок** через `print()`;
- один коментар на початку коду.

**Приклад бажаного результату** (можна зробити інший дизайн):

```text
============================
      ДЕНЬ НАУКИ
============================

Місце: актова зала
Дата: 15 листопада
Приходь досліджувати світ!
```

**Підказка, якщо складно:** спочатку запиши всі потрібні рядки на папері, тоді кожен рядок, який треба вивести, перетвори на `print("...")`. Для порожнього рядка використай `print()`.

**Критерії успіху:** інформація зрозуміла; усі дужки й лапки закриті; афіша виводиться без помилок; код містить коментар.

### Завдання 4. «Знайди та виправ» — 4 хв

У кожному фрагменті є **одна** помилка. Не копіюй усі фрагменти до одного файлу: перевіряй по одному. Знайди причину, перепиши правильно та запусти.

**А**
```python
Print("Вітаю!")
```

**Б**
```python
print("Моя перша програма"
```

**В**
```python
print("Я вивчаю Python)
```

**Г**
```python
pritn("Готово")
```

Поясни своїми словами: яка частина запису заважає Python виконати кожну команду?

<details>
<summary>🔐 Відповіді для самоперевірки — відкрий після виправлення</summary>

```python
print("Вітаю!")
print("Моя перша програма")
print("Я вивчаю Python")
print("Готово")
```

- **А:** `Print` → `print` (важливий регістр).
- **Б:** бракує `)`.
- **В:** бракує закривальних лапок `"`.
- **Г:** переплутані літери в назві `print`.

</details>

## 🟣 Рівень 3. Підвищений: творчий виклик (додатково)

### Завдання 5. «Текстовий логотип»

Створи `practice01_logo.py` і виведи **текстовий логотип** у стилі гри, каналу або власного проєкту. Умови:

- щонайменше **п'ять** рядків виведення;
- використай декоративні символи (`*`, `=`, `/`, `|`, `_` або інші);
- додай один пояснювальний коментар;
- усі символи логотипа мають виводитися функцією `print()`.

**Один із можливих результатів:**

```text
+------------------+
|    PYTHON LAB    |
|   CODE • CREATE  |
+------------------+
```

> Якщо в твоєму дизайні є символ `\`, пам'ятай: усередині текстового рядка для його виведення зазвичай записують `\\`.

### Завдання 6. «Передбач результат»

Не запускаючи програму, запиши у зошиті її майбутній вивід. Лише потім перевір у Thonny.

```python
print("Старт")
print()
print("Один", "два")
# Це пояснення
print("Фініш")
```

<details>
<summary>✅ Перевір прогноз</summary>

```text
Старт

Один два
Фініш
```

Між `Один` і `два` з'являється пробіл, бо `print()` за замовчуванням розділяє аргументи пробілом. Коментар у результаті відсутній.

</details>
