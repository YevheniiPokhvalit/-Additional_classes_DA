# Урок 2. Змінні та типи даних

## 1. Пригадай попередній урок

Не запускаючи код, скажи, що буде у виводі:

```python
# Моя картка
print("Мене звати Алекс")
print("Мені 16 років")
```

Коментар не виводиться. Два виклики `print()` виводять два рядки. Але що робити, якщо ім’я треба використати в десяти повідомленнях? Зручно записати його один раз і звертатися до нього за назвою.

## 2. Що таке змінна

**Змінна — це ім’я, пов’язане зі значенням.** Через це ім’я програма може використовувати значення далі.

```python
nickname = "Pixel"
print(nickname)
```

Результат:

```text
Pixel
```

Розберімо присвоєння:

| Частина | Значення |
|---|---|
| `nickname` | Назва змінної. |
| `=` | Присвоєння: обчислити праву частину й пов’язати результат з ім’ям ліворуч. |
| `"Pixel"` | Значення — текстовий рядок. |

`=` тут не є запитанням «чи рівні ці значення?». Команду читаємо: «присвоїти змінній `nickname` значення `"Pixel"`».

Змінну створюємо **до першого використання**. Python виконує рядки зверху вниз.

### Ім’я в лапках і без лапок

```python
nickname = "Pixel"
print(nickname)
print("nickname")
```

```text
Pixel
nickname
```

Без лапок Python шукає значення змінної. У лапках він бачить буквальний текст.

## 3. Як називати змінні

Для наших програм використовуємо зрозумілі англійські назви маленькими літерами; слова розділяємо `_`:

```python
player_name = "Pixel"
player_age = 16
school_class = 11
```

Правила Python:

- Назва може містити літери, цифри та `_`, але не починається з цифри.
- Пробіли та дефіс `-` у назві не використовуємо.
- Регістр важливий: `age` та `Age` — різні імена.
- Службові слова, наприклад `class`, не можна використовувати як назви змінних.

Python дозволяє багато неанглійських літер в іменах, але для послідовності в цьому курсі використовуємо латиницю. Український текст у лапках залишається українським.

| Невдалий запис | Кращий варіант |
|---|---|
| `2player` | `player2` |
| `player name` | `player_name` |
| `player-name` | `player_name` |
| `class` | `school_class` |
| `a` для віку | `age` |

**Не називай свої змінні `print`, `str`, `int`, `float`, `type` або `input`:** ці імена потрібні для вбудованих можливостей Python. Це не службові слова, але перевизначення заважатиме подальшій роботі.

## 4. Три типи даних

Значення має **тип**, який визначає, що це за дані та як із ними можна працювати.

| Тип | Що зберігає | Приклади |
|---|---|---|
| `str` | Текстовий рядок. | `"Pixel"`, `"16"`, `"11 клас"` |
| `int` | Ціле число. | `16`, `0`, `-3` |
| `float` | Число з дробовою частиною; у комп’ютері зберігається наближено. | `1.75`, `0.5`, `-2.0` |

```python
nickname = "Pixel"
age = 16
height_m = 1.75
```

Зверни увагу:

- `16` — число, а `"16"` — текст.
- Дробову частину в коді відокремлюємо **крапкою**, а не комою.
- `1.0` — `float`, навіть якщо його числове значення дорівнює цілому числу.
- Типів у Python більше; сьогодні достатньо цих трьох.

### Як дізнатися тип

```python
print(type("16"))
print(type(16))
print(type(1.75))
```

```text
<class 'str'>
<class 'int'>
<class 'float'>
```

`type()` визначає тип значення; зовнішній `print()` показує відповідь. У написі `<class 'int'>` слово `int` — назва типу, який нас цікавить. Створювати власні класи для цього не потрібно.

## 5. Виведення змінних

З уроку 1 ми знаємо, що `print()` може приймати кілька значень через кому. Це працює і зі змінними:

```python
nickname = "Pixel"
age = 16
print("Гравець:", nickname)
print("Вік:", age)
```

```text
Гравець: Pixel
Вік: 16
```

Коми тут розділяють аргументи функції. `print()` сам поставить між ними пробіли. Щоб показати текст поруч із числом, сьогодні використовуй саме цей спосіб.

## 6. Повторне присвоєння

```python
level = 1
print("Рівень:", level)
level = 2
print("Новий рівень:", level)
```

```text
Рівень: 1
Новий рівень: 2
```

Друге присвоєння змінює значення, пов’язане з ім’ям `level`. Уже надрукований рядок не змінюється.

### Копіювання значення: важливий приклад

```python
score = 10
saved_score = score
score = 25
print(score)
print(saved_score)
```

```text
25
10
```

У момент `saved_score = score` обидва імені пов’язані зі значенням `10`. Подальше присвоєння нового числа змінній `score` не переприсвоює `saved_score`. Цей приклад стосується числових значень; зі змінюваними колекціями познайомимося пізніше.

Python дозволяє пов’язати ім’я зі значенням іншого типу:

```python
level = 2
level = "другий"
print(type(level))
```

Результат — `<class 'str'>`. Але для зрозумілості краще не змінювати призначення змінної без потреби. Не потрібно заздалегідь писати тип перед її назвою.

## 7. Розібраний приклад: нова візитівка

Відкрий [Приклади/01_card.py](Приклади/01_card.py).

```python
# Дані змінюємо тут, а оформлення залишаємо нижче.
nickname = "Pixel"
age = 16
school_class = 11
interests = "музика, ігри, програмування"
study_goal = "створити власну гру"

print("============================")
print("МОЯ ВІЗИТІВКА")
print("Ім'я:", nickname)
print("Вік:", age)
print("Клас:", school_class)
print("Інтереси:", interests)
print("Мета:", study_goal)
print("============================")
```

Спочатку програма створює змінні, потім використовує їх у повідомленнях. Щоб змінити профіль, достатньо відредагувати значення на початку.

**Експеримент:** зміни `nickname`, запусти програму та поясни, чому змінився лише рядок з іменем. Потім додай змінну `favorite_subject` і виведи її.

## 8. Типові помилки

| Помилка | Причина та виправлення |
|---|---|
| `print(age)` до створення `age` | Ім’я ще невідоме: `NameError`. Спочатку присвой значення. |
| `age = 16`, потім `print(Age)` | Різні імена. Використовуй однаковий регістр. |
| `nickname = Pixel` | Без лапок `Pixel` вважається назвою змінної. Для тексту потрібно `"Pixel"`. |
| `16 = age` | Ліворуч має бути допустима ціль присвоєння, у нашому випадку ім’я: `age = 16`. |
| `print("age")` замість виведення віку | Програма виконується, але друкує слово `age`. Для значення використовуй `print(age)`. |

Алгоритм виправлення: прочитай останній рядок повідомлення → знайди рядок коду → перевір ім’я й лапки → зміни одну причину → запусти знову.

## 9. Мінісловник

| Поняття | Значення |
|---|---|
| Змінна | Ім’я, через яке використовуємо значення. |
| Присвоєння | Пов’язування імені зі значенням через `=`. |
| Тип даних | Визначає вид значення та доступні операції. |
| `str` / `int` / `float` | Текст / ціле число / число з дробовою частиною. |
| `type()` | Визначає тип значення. |

## 10. Самоперевірка

1. Чим відрізняються `print(name)` та `print("name")`?
2. Які типи мають `"11"`, `11`, `11.0`?
3. Чому не можна назвати змінну `player name`?
4. Що означає `=` у `age = 16`?
5. Що виведе код нижче?

```python
city = "Львів"
old_city = city
city = "Київ"
print(old_city)
print(city)
```
