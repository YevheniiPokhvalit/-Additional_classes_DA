# Урок 4. Арифметичні операції та обчислення

## 1. Пригадай урок 3

```python
days = int(input("Кількість днів: "))
minutes_per_day = int(input("Хвилин на день: "))
total_minutes = days * minutes_per_day
print(f"Разом: {total_minutes} хв")
```

Поясни: навіщо тут `int()`? Який результат для `5` і `20`? Чому `input()` без перетворення не дає числа?

Сьогодні доповнимо вже знайомі `+` та `*` іншими операціями й навчимося записувати формули.

## 2. Арифметичні оператори

**Оператор** — позначення дії. Значення, над якими виконується дія, називають **операндами**: у `7 + 3` це числа `7` і `3`.

| Оператор | Дія | Приклад | Результат |
|---|---|---|---|
| `+` | Додавання | `7 + 3` | `10` |
| `-` | Віднімання | `7 - 3` | `4` |
| `*` | Множення | `7 * 3` | `21` |
| `/` | Звичайне ділення | `7 / 2` | `3.5` |
| `//` | Ділення з округленням униз | `7 // 2` | `3` |
| `%` | Остача від ділення | `7 % 2` | `1` |
| `**` | Піднесення до степеня | `7 ** 2` | `49` |

Для множення потрібен символ `*`: математичний запис `2a` у коді замінюємо на `2 * a`. Для степеня використовуємо `**`, а не `^`: у Python `^` має інше призначення.

Результат можна одразу показати, але для задач зручно спочатку записати його у змінну:

```python
side = 5
area = side ** 2
print(f"Площа квадрата: {area} кв. см")
```

Результат: `Площа квадрата: 25 кв. см`.

## 3. Три різні відповіді на питання про ділення

Маємо 17 наліпок. Розкладаємо їх у набори по 5 наліпок:

```python
stickers = 17
pack_size = 5
print(stickers / pack_size)
print(stickers // pack_size)
print(stickers % pack_size)
```

```text
3.4
3
2
```

- `/` відповідає: яке числове відношення? Отримали `3.4`.
- `//` відповідає: скільки **повних наборів**? Отримали `3`.
- `%` відповідає: скільки наліпок **залишиться**? Отримали `2`.

Перевірка: `3 * 5 + 2` дорівнює `17`. Якщо наліпок `20`, буде 4 повні набори й остача 0.

### Що відбувається з типами

```python
print(8 / 2)
print(8 // 2)
```

```text
4.0
4
```

Звичайне ділення цілих чисел дає `float`, навіть коли ділення відбулося без остачі. `//` для двох `int` дає `int`. Якщо один операнд `float`, наприклад `8.0 // 2`, результат теж буде `float`: `4.0`.

### Важлива точність: `//` округлює вниз

Для невід’ємних чисел можна думати про кількість повних груп. Але `//` не просто «відкидає дробову частину»:

```python
print(-7 // 2)
```

Результат `-4`, адже це найближче ціле **не більше** за `-3.5`. Основні задачі уроку використовують невід’ємні кількості; цей приклад допомагає не запам’ятати хибне правило.

Ділити на нуль не можна: `/`, `//` і `%` з нулем праворуч спричиняють `ZeroDivisionError`. Нуль у чисельнику дозволений, наприклад `0 / 5` дає `0.0`.

## 4. Порядок виконання дій

Для виразів цього уроку:

1. Спочатку дії в дужках.
2. Потім степені `**`.
3. Потім `*`, `/`, `//`, `%` — одного пріоритету, зліва направо.
4. Потім `+`, `-` — одного пріоритету, зліва направо.

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
print(20 / 5 * 2)
```

```text
14
20
8.0
```

Останній вираз — `(20 / 5) * 2`, а не `20 / (5 * 2)`.

### Перекладаємо формулу у Python

Для середнього двох чисел спочатку додаємо, потім ділимо:

```python
first = 8
second = 10
average = (first + second) / 2
print(f"Середнє: {average}")
```

Отримаємо `Середнє: 9.0`. Без дужок `first + second / 2` означає іншу формулу й дає `13.0`.

**Правило для роботи:** спочатку запиши формулу словами або на папері, потім перетвори її на код і перевір на простих числах.

<details>
<summary>Додатково: степені та від’ємні числа</summary>

Степені обчислюються справа наліво: `2 ** 3 ** 2` означає `2 ** (3 ** 2)` і дає `512`.

`-3 ** 2` означає `-(3 ** 2)` і дає `-9`, а `(-3) ** 2` дає `9`. Якщо хочеш піднести до степеня саме від’ємне число, використовуй дужки. Ці випадки не входять до обов’язкової практики.

</details>

## 5. Відсотки в обчисленнях

Один відсоток — одна сота. Щоб знайти 10% від суми, множимо її на `10 / 100`:

```python
subtotal = 240.0
discount_percent = 10.0
discount = subtotal * discount_percent / 100
after_discount = subtotal - discount
print(f"Знижка: {discount} грн")
print(f"Після знижки: {after_discount} грн")
```

Результат — `24.0` грн знижки та `216.0` грн після знижки. Уважно прочитай умову: якщо знижка стосується товарів, доставку додаємо вже **після** обчислення знижки на товари.

## 6. Округлення та оформлення результату

### `round()` — отримати округлене число

```python
value = 10 / 3
rounded_value = round(value, 2)
print(rounded_value)
```

Отримаємо `3.33`. Другий аргумент `2` задає кількість знаків після десяткової крапки. `round()` не гарантує показ усіх нулів: `print(round(12.5, 2))` показує `12.5`.

### `:.2f` — показати рівно два знаки

```python
price = 12.5
print(f"Ціна: {price:.2f} грн")
```

```text
Ціна: 12.50 грн
```

Уже знайомий f-рядок отримав нову частину: `:.2f` після назви змінної. Вона форматує число з двома знаками після крапки. Це змінює **відображення**, а не значення змінної. Наприклад, для `10 / 3` побачимо `3.33`, але початковий результат лишиться доступним для подальших обчислень.

У проміжних обчисленнях зберігай початкові значення, а оформлення додавай під час виведення. Так не накопичуватиметься зайве округлення на кожному кроці.

> `float` зберігає деякі дроби наближено. Не вважай `round()` правилом «п’ять завжди вгору»: наприклад, `round(2.5)` дає `2`, а `round(3.5)` — `4`. Для точних половин Python обирає парний результат, а двійкове наближення теж може впливати на округлення. У наших навчальних оцінках вартості достатньо `float` та `:.2f`; для реального грошового обліку потрібні окремі правила точності.

## 7. Розібраний приклад: рахунок між друзями

Відкрий [Приклади/01_split_bill.py](Приклади/01_split_bill.py).

```python
# Кількість людей має бути більшою за нуль.
bill = float(input("Сума рахунку, грн: "))
people = int(input("Кількість людей: "))

share = bill / people

print(f"Орієнтовно з кожного: {share:.2f} грн")
```

Приклад діалогу:

```text
Сума рахунку, грн: 360
Кількість людей: 4
Орієнтовно з кожного: 90.00 грн
```

`360` та `4` у діалозі вводить користувач, а не друкує програма. Поділ `100` на `3` покаже `33.33` грн на людину. Це округлений орієнтир: три такі платежі дадуть `99.99`, тому точний розподіл копійок потребував би окремої задачі.

## 8. Розібраний приклад: години та хвилини

Відкрий [Приклади/02_minutes.py](Приклади/02_minutes.py).

```python
total_minutes = int(input("Тривалість у хвилинах: "))
hours = total_minutes // 60
minutes = total_minutes % 60
print(f"Тривалість: {hours} год {minutes} хв")
```

Для `135` отримаємо `Тривалість: 2 год 15 хв`: дві повні години й 15 хвилин залишку. Для `60` — `1 год 0 хв`, для `0` — `0 год 0 хв`.

Перевір себе: `hours * 60 + minutes` має відновити початкову кількість хвилин. За невід’ємного введення залишок завжди від 0 до 59 включно.

## 9. Типові помилки

| Помилка | Що сталося | Виправлення |
|---|---|---|
| `total / people`, коли `people` дорівнює 0 | `ZeroDivisionError`. | Для цього уроку введи додатну кількість людей і перезапусти. |
| `minutes = total_minutes / 60` для залишку хвилин | Обрано звичайне ділення. | Для залишку потрібне `% 60`, для повних годин — `// 60`. |
| `average = first + second / 2` | Неправильний порядок дій для середнього. | Написати `(first + second) / 2`. |
| `area = side ^ 2` | `^` не означає степінь у Python. | Написати `side ** 2`. |
| `price = input(...)`, потім арифметика | Залишився рядок, можливі помилка або інший зміст дії. | Перетворити введення через `float()` або `int()`. |
| `print(round(12.5, 2))` не показує `12.50` | Округлення числа не задає ширину відображення. | Для двох знаків використати f-рядок із `:.2f`. |

Не додавай умови або `try` / `except`, яких ще не було. Сьогодні важливо розуміти формулу, область допустимого введення й причину помилки.
