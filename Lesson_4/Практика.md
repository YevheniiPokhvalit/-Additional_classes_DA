### 2. Тривалість відео — 5 хв

Доповни `practice04_video.py`. Позначки `___` заміни потрібними операторами.

```python
total_minutes = int(input("Тривалість відео у хвилинах: "))
hours = total_minutes ___ 60
minutes = total_minutes ___ 60
print(f"Відео триває: {hours} год {minutes} хв")
```

| Введення | Очікуваний останній рядок |
|---|---|
| `135` | `Відео триває: 2 год 15 хв` |
| `60` | `Відео триває: 1 год 0 хв` |
| `59` | `Відео триває: 0 год 59 хв` |
| `0` | `Відео триває: 0 год 0 хв` |

Усно перевір: години, помножені на 60, плюс хвилини мають дати початкове введення.

## Рівень 2. Самостійно

### 3. Покупка для спільного проєкту — 8 хв

Створи `practice04_order.py`. Потрібно замовити кілька однакових матеріалів для шкільного проєкту.

Програма запитує ціну за одиницю (`float`), кількість (`int`), знижку у відсотках (`float`) та доставку (`float`). Припускаємо: ціна й доставка невід’ємні, кількість додатна, знижка від 0 до 100 включно.

В окремих змінних обчисли:

1. Вартість товарів до знижки: ціна × кількість.
2. Суму знижки: вартість товарів × відсоток / 100.
3. Підсумок: вартість товарів − знижка + доставка.

Знижка **не поширюється на доставку**. Покажи три результати з підписами `Товари:`, `Знижка:`, `До сплати:` та двома знаками після крапки. Не округлюй проміжні змінні.

| Ціна | Кількість | Знижка, % | Доставка | Товари | Сума знижки | До сплати |
|---|---|---|---|---|---|---|
| `80` | `3` | `10` | `40` | `240.00` | `24.00` | `256.00` |
| `12.5` | `4` | `0` | `0` | `50.00` | `0.00` | `50.00` |
| `100` | `2` | `100` | `30` | `200.00` | `200.00` | `30.00` |

Наприклад, останній рядок для першої перевірки: `До сплати: 256.00 грн`.

### 4. Майстерня помилок — 5 хв

Усі фрагменти синтаксично допустимі, але формули не відповідають задуму. Перевіряй окремо: передбач результат → запусти → виправ → поясни.

**А. Середнє двох чисел має дорівнювати 9.0.**
```python

second = 10

```

**Б. Площа квадрата зі стороною 4 має дорівнювати 16.**
```python

```

**В. Для 125 хвилин має вийти 2 год 5 хв.**
```python
total_minutes = 125
hours = total_minutes % 60
minutes = total_minutes // 60
print(f"{hours} год {minutes} хв")
```

**Г. Знижка 10% від 200 грн має дорівнювати 20.0 грн.**
```python
subtotal = 200.0
discount_percent = 10.0
discount = subtotal * discount_percent
print(discount)
```

### 5. Залишок копійок

Для `10000` копійок і `3` людей:

```text
Базова частка: 3333 коп.
Залишок для розподілу: 1 коп.
```

Для точного розподілу одна людина має додати до базової частки одну копійку. Виведи тільки базову частку та залишок: автоматично призначати платежі людям поки не потрібно. Перевір, що `базова частка * люди + залишок` відновлює рахунок. Порівняй з округленим прикладом із теорії.

### Обов’язково: «Калькулятор поїздки» — 15–20 хв

Створи `homework04_trip.py`. Обчисли орієнтовну вартість пального для автомобільної поїздки.

Запитай:

- загальну відстань маршруту у кілометрах — `float` (усі ділянки, включно зі зворотною дорогою, якщо вона є);
- витрату пального у літрах на 100 км — `float`;
- ціну одного літра у гривнях — `float`;
- кількість людей, між якими ділять витрати, — `int`, більше нуля.

Ціни тут умовні, їх вводить користувач. Використовуй невід’ємні відстань, витрату й ціну. Не додавай власну перевірку введення.

Формули:

```text
пальне = відстань * витрата_на_100_км / 100
вартість = пальне * ціна_літра
частка = вартість / кількість_людей
```

Збережи три результати в окремих змінних. Виведи `Потрібно пального:`, `Вартість пального:` та `Орієнтовно з кожного:` з одиницями та рівно двома знаками після крапки. Додай коментарі перед введенням і обчисленнями.

Перевірочні дані:

| Відстань | Л/100 км | Ціна літра | Люди | Пальне, л | Вартість, грн | Частка, грн |
|---|---|---|---|---|---|---|
| `150` | `8` | `50` | `3` | `12.00` | `600.00` | `200.00` |
| `100` | `6.5` | `48` | `4` | `6.50` | `312.00` | `78.00` |
| `0` | `8` | `50` | `2` | `0.00` | `0.00` | `0.00` |

Приклад діалогу для першого набору:

```text
Відстань маршруту, км: 150
Витрата пального, л/100 км: 8
Ціна літра, грн: 50
Кількість людей: 3

Потрібно пального: 12.00 л
Вартість пального: 600.00 грн
Орієнтовно з кожного: 200.00 грн
```

Це навчальна оцінка витрат лише на пальне: фактична витрата може змінюватися. Для частки з дробовими копійками діє зауваження про округлення з теорії.
