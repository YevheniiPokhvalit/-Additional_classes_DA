# Урок 5. Рядки: обробка та оформлення тексту

**Мета:** отримувати й очищувати текст, визначати його довжину, звертатися до символів і частин рядка, змінювати регістр та оформлювати вивід.

**Потрібно знати:** змінні, типи даних, введення через input(), перетворення int() і float(), арифметику, print() та f-рядки з уроків 1–4.

Після заняття ти зможеш підготувати текстову картку з даних користувача та пояснити, чому короткий або порожній текст потребує уваги.

## 1. Пригадай попередні уроки

Передбач результат, потім перевір:

```python
nickname = "Nova"
age = 16
print(f"Гравець: {nickname}. Вік: {age}")
print("12" + "3")
print(12 + 3)
```

Останні два результати — текст 123 і число 15. Від типу даних залежить зміст операції. Сьогодні працюємо з типом str.

## 2. Рядок і його довжина

**Рядок** — послідовність символів. У коді текст записують у лапках; input() також повертає рядок.

```python
word = "Python"
print(word)
print(len(word))
```

```text
Python
6
```

**len()** повертає кількість елементів рядка як ціле число. Для звичайних українських і латинських літер у прикладах уроку це кількість символів. Пробіли та розділові знаки теж враховуються.

```python
print(len("Привіт!"))
print(len("А Б"))
print(len(""))
print(len("   "))
```

```text
7
3
0
3
```

Порожній рядок має довжину 0. Рядок із трьох пробілів має довжину 3, хоча на екрані він може здаватися порожнім.

> Складні емодзі й деякі поєднання літер із додатковими знаками можуть складатися з кількох елементів рядка. У цьому уроці для перевірок використовуємо звичайні літери, цифри й розділові знаки.

## 3. Індекси: отримати один символ

**Індекс** — позиція елемента в рядку. Нумерація починається з нуля.

```python
word = "Python"
print(word[0])
print(word[2])
print(word[5])
```

```text
P
t
n
```

| Символ | P | y | t | h | o | n |
|---|---|---|---|---|---|---|
| Індекс від початку | 0 | 1 | 2 | 3 | 4 | 5 |
| Індекс від кінця | -6 | -5 | -4 | -3 | -2 | -1 |

Від’ємні індекси рахують від кінця: -1 — останній символ, -2 — передостанній.

```python
print(word[-1])
print(word[-2])
```

```text
n
o
```

Квадратні дужки після рядка або змінної означають звернення до елемента. Лапки навколо індексу не потрібні.

### Довжина та останній індекс — різні числа

У слові Python шість символів, але останній індекс від початку — 5. Для непорожнього рядка він дорівнює len(word) - 1.

Наступний фрагмент **помилковий**; перевіряй його окремо:

```python
word = "Python"
print(word[6])
```

Виникне **IndexError**: символа з індексом 6 немає. У порожньому рядку немає навіть елемента з індексом 0 або -1.

**Правило для цього уроку:** індексацію застосовуємо до відомого непорожнього тексту з достатньою довжиною. Для довільного введення, яке може бути порожнім, використовуємо безпечні зрізи. Перевіряти довжину умовою навчимося на наступних заняттях.

## 4. Зрізи: отримати частину рядка

**Зріз** має вигляд text[start:stop]. Беремо символи від start включно до stop, **не включаючи stop**.

```python
word = "Python"
print(word[0:2])
print(word[2:5])
```

```text
Py
tho
```

У word[2:5] потрапили символи з індексами 2, 3 і 4.

Якщо початок пропущено, беремо від початку рядка. Якщо кінець пропущено — до кінця.

| Запис | Що отримуємо для word = "Python" | Результат |
|---|---|---|
| word[:3] | Перші три символи | Pyt |
| word[3:] | Від індексу 3 до кінця | hon |
| word[-2:] | Останні два символи | on |
| word[:] | Увесь рядок | Python |
| word[:100] | Усе, що є до вказаної межі | Python |
| word[4:2] | Порожній зріз за такого порядку меж | порожній рядок |

### Короткий і порожній текст

```python
short_text = "Я"
empty_text = ""
print(f"Короткий: [{short_text[:3]}]")
print(f"Порожній: [{empty_text[:3]}]")
print(f"Перша літера зрізом: [{empty_text[:1]}]")
```

```text
Короткий: [Я]
Порожній: []
Перша літера зрізом: []
```

Межа зрізу може виходити за довжину — отримаємо наявну частину. На відміну від empty_text[0], вираз empty_text[:1] не спричиняє IndexError. Квадратні дужки в самому повідомленні допомагають побачити, де починається й закінчується результат.

**Перевір себе:** що повернуть "Панда"[1:4] та "Панда"[-1:]?

## 5. Методи рядків: дії через крапку

**Метод** — дія, яку викликаємо для певного значення. Записуємо рядок або змінну, крапку, назву методу й дужки:

```python
nickname = "  Nova  "
clean_nickname = nickname.strip()
print(f"Було: [{nickname}]")
print(f"Стало: [{clean_nickname}]")
```

```text
Було: [  Nova  ]
Стало: [Nova]
```

len(nickname) — виклик функції з аргументом; nickname.strip() — виклик методу рядка. Дужки потрібні в обох випадках.

### 5.1. strip(): прибрати зайві пробільні символи з країв

Без аргументів strip() прибирає пробіли, табуляцію та переходи рядка **на початку й у кінці**. Усередині тексту вони залишаються.

```python
text = "  Привіт,  друже!  "
clean_text = text.strip()
print(f"[{clean_text}]")
print(len("   ".strip()))
```

```text
[Привіт,  друже!]
0
```

Два пробіли між комою і словом друже не зникли. strip() не виправляє весь текст автоматично.

### 5.2. lower() та upper(): змінити регістр

```python
nickname = "PyThOn"
print(nickname.lower())
print(nickname.upper())
print(nickname)
```

```text
python
PYTHON
PyThOn
```

lower() переводить літери в нижній регістр, upper() — у верхній. Цифри й символи на кшталт _ не змінюються. Ці методи працюють і зі звичайними українськими літерами.

### 5.3. replace(): замінити фрагмент

```python
message = "Привіт, друже!"
new_message = message.replace("друже", "командо")
print(new_message)
print(message)
```

```text
Привіт, командо!
Привіт, друже!
```

У цьому записі перший аргумент — що шукаємо, другий — на що замінюємо. Без додаткового аргументу replace() замінює **всі** точні входження фрагмента.

```python
print("так-так-так".replace("так", "ні"))
print("Nova nova".replace("nova", "echo"))
```

```text
ні-ні-ні
Nova echo
```

Пошук чутливий до регістру: Nova і nova — різні фрагменти. Якщо шуканого тексту немає, результат дорівнює початковому тексту.

## 6. Рядки незмінювані: збережи результат

Методи обробки повертають результат, але не редагують початковий рядок на місці.

```python
nickname = "  Nova  "
nickname.strip()
print(f"[{nickname}]")
```

```text
[  Nova  ]
```

Результат strip() не збережено. Потрібно присвоїти його іншій змінній або тому самому імені:

```python
nickname = nickname.strip()
print(f"[{nickname}]")
```

```text
[Nova]
```

Змінити символ через nickname[0] = "R" не можна: виникне TypeError. Можна скласти новий текст зі зрізів і зв’язати його зі змінною:

```python
nickname = "Nova"
nickname = "R" + nickname[1:]
print(nickname)
```

```text
Rova
```

### Послідовна обробка

Спочатку зручніше записувати кожен крок окремо:

```python
raw_nickname = "  Nova Star  "
clean_nickname = raw_nickname.strip()
lower_nickname = clean_nickname.lower()
profile_id = lower_nickname.replace(" ", "_")
print(profile_id)
```

```text
nova_star
```

Після пояснення кроків можна скоротити:

```python
profile_id = raw_nickname.strip().lower().replace(" ", "_")
```

Дії відбуваються зліва направо: результат попереднього методу стає рядком для наступного. Кожен звичайний пробіл замінюється окремо: два внутрішні пробіли дадуть два символи _. Це навчальне правило оформлення, а не повна перевірка допустимості імені.

## 7. Спеціальні символи у тексті

Усередині звичайного рядка зворотна коса риска починає спеціальну послідовність.

| Запис у коді | Що з’являється у виводі |
|---|---|
| `\n` | Перехід на новий рядок |
| `\t` | Горизонтальна табуляція |
| `\\` | Одна зворотна коса риска |

### Перехід на новий рядок: `\n`

```python
print("Перший рядок\nДругий рядок")
```

```text
Перший рядок
Другий рядок
```

Один виклик print() може вивести кілька рядків. Пара символів `\n` у коді позначає **один** символ у значенні рядка:

```python
print(len("А\nБ"))
```

Результат — 3: літера А, перехід рядка та літера Б.

### Табуляція: `\t`

```python
print("Поле\tЗначення")
print("Клас\t11")
```

Табуляція переміщує текст до наступної позиції табуляції. Ширина відступу залежить від середовища й попереднього тексту: це не обов’язково чотири пробіли. Для підписів різної довжини вирівнювання може відрізнятися.

### Зворотна коса риска: `\\`

```python
print("C:\\Python_11\\lesson05.py")
```

```text
C:\Python_11\lesson05.py
```

Це лише **виведення тексту шляху**, файл за цим шляхом не створюється. Щоб показати буквально `\n`, а не зробити перехід рядка, запиши подвійну зворотну косу риску перед n:

```python
print("Позначення переходу: \\n")
```

```text
Позначення переходу: \n
```

Це пояснює і запис `\\` для текстового малюнка з уроку 1.

## 8. Розібраний приклад: коротке повідомлення профілю

Відкрий [Приклади/02_profile_message.py](Приклади/02_profile_message.py).

```python
# Зберігаємо введений текст, щоб порівняти його з результатом.
raw_nickname = input("Псевдонім: ")
raw_message = input("Повідомлення: ")

clean_nickname = raw_nickname.strip()
profile_id = clean_nickname.lower().replace(" ", "_")
clean_message = raw_message.strip().replace("!", ".")
preview = clean_message[:10]

print("ПРОФІЛЬ\n--------")
print(f"Ідентифікатор: [{profile_id}]")
print(f"Довжина ідентифікатора: {len(profile_id)}")
print(f"Повідомлення: [{clean_message}]")
print(f"Перші 10 символів: [{preview}]")
```

Для псевдоніма з двома пробілами з кожного краю "  Nova Star  " та повідомлення "  Привіт, друже!  " підсумковий вивід:

```text
ПРОФІЛЬ
--------
Ідентифікатор: [nova_star]
Довжина ідентифікатора: 9
Повідомлення: [Привіт, друже.]
Перші 10 символів: [Привіт, др]
```

1. input() отримує два рядки разом із пробілами, які ввів користувач.
2. strip() прибирає пробільні символи лише з країв.
3. lower() і replace() оформлюють ідентифікатор.
4. Інший replace() замінює всі знаки оклику крапками за правилом цього прикладу.
5. Зріз бере щонайбільше десять перших символів повідомлення.
6. len() рахує довжину вже підготовленого ідентифікатора.
7. `\n` і f-рядки оформлюють вивід.

**Експеримент:** введи Я як псевдонім і порожнє повідомлення. Потім натисни Enter для обох відповідей. Програма має завершитися без IndexError: у ній немає звернення до окремого символа за індексом.

## 9. Типові помилки

| Симптом або помилковий запис | Причина | Виправлення |
|---|---|---|
| word[6] для слова Python | Індекс дорівнює довжині; такого елемента немає | Для останнього символа відомого непорожнього рядка використати word[-1] |
| nickname[0] після порожнього введення | У рядку немає елементів | Для безпечного отримання першого символа або порожнього рядка використати nickname[:1] |
| name.strip(), але пробіли лишилися | Повернене значення не збережено | name = name.strip() |
| name.upper без дужок | Метод не викликано | name.upper() |
| name[0] = "A" | Символи рядка не можна змінювати на місці | Створити новий рядок і виконати присвоєння |
| word[1:4] повертає три символи | Права межа не входить до зрізу | Врахувати індекси 1, 2 і 3 |
| replace() не знайшов слово | Регістр або фрагмент не збігається | Перевірити точний текст для заміни |
| "А/nБ" показує /n буквально | Використано пряму риску | Для переходу рядка потрібно `\n` |

Перевіряй помилкові приклади окремо. Читай останній рядок повідомлення, змінюй одну причину й запускай знову. Умови, цикли й обробку винятків для цих вправ поки не додаємо.

## 10. Мінісловник

| Поняття | Значення |
|---|---|
| Рядок | Послідовність символів, тип str |
| Довжина | Кількість елементів; отримуємо через len() |
| Індекс | Позиція елемента; від початку рахуємо з 0 |
| Зріз | Частина рядка між заданими межами |
| Метод | Дія для значення, яку викликаємо через крапку |
| Регістр | Великі або малі літери |
| Незмінюваність | Неможливість редагувати окремі символи рядка на місці |
| Спеціальна послідовність | Запис на кшталт `\n`, що позначає спеціальний символ |
