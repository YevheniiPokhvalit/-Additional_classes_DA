## Рівень 1. За зразком

### 1. Перше знайомство — 4 хв

Збережи як `practice03_greeting.py`:

```python
nickname = input("Псевдонім: ")
print(f"Вітаю, {nickname}!")
```

Додай запитання про улюблений шкільний предмет і повідомлення `Твій улюблений предмет — ... .` без пробілу перед крапкою.

Приклад повного діалогу:

```text
Псевдонім: Nova
Улюблений предмет: інформатика
Вітаю, Nova!
Твій улюблений предмет — інформатика.
```

Розташуй обидва введення перед обома повідомленнями. Запусти вдруге з іншими відповідями: код редагувати не потрібно.

### 2. Вік через рік — 5 хв

У файлі `practice03_age.py` доповни пропуски. `___` — позначення місця для заміни, а не готовий код.

```python
age_text = input("Твій вік: ")
age = ___(age_text)
next_age = age + ___
print(f"Через рік: {___}")
```

| Введення | Останній рядок виводу |
|---|---|
| `16` | `Через рік: 17` |
| `17` | `Через рік: 18` |

Додатково виведи `type(age_text)` і `type(age)`; поясни різницю.

## Рівень 2. Самостійно

### 3. Маршрут із двох частин — 6 хв

Створи `practice03_route.py`:

1. Запитай дві відстані у кілометрах через `float()`.
2. Обчисли їхню суму в окремій змінній.
3. Через f-рядок виведи `Загальна відстань: ... км`.

| Перша відповідь | Друга відповідь | Очікуваний останній рядок |
|---|---|---|
| `2.5` | `1.5` | `Загальна відстань: 4.0 км` |

| `1.25` | `0.75` | `Загальна відстань: 2.0 км` |

**Підказка:** спочатку запиши етапи словами: введення першого числа → введення другого → сума → повідомлення.

### 4. Знайди причину — 5 хв

Фрагменти перевіряй окремо. Спочатку передбач результат або помилку, потім запусти та виправ.

**А. Має вийти число 17 для введення 16.**
```python
age = input("Вік: ")
print(age + 1)
```

**Б. Має вивести введений псевдонім у привітанні.**
```python
nickname = input("Псевдонім: ")
print("Привіт, {nickname}!")
```

**В. Має обчислити числову суму двох цілих чисел. Введи 12 та 13.**
```python
first = input("Перше число: ")
second = input("Друге число: ")
print(first + second)
```

**Г. Має прийняти дробову відстань 2.5.**
```python
distance = int(input("Відстань у км: "))
print(distance)
```

У `practice03_debug.md` або зошиті запиши: причина → виправлення. Які два фрагменти виконуються без винятку, але не відповідають вимозі?

## Рівень 3. Додатковий виклик

### 5. Час на підготовку

Створи `practice03_study.py`. Запитай псевдонім, кількість днів підготовки та кількість хвилин на день. Кількості — цілі невід’ємні числа. Обчисли загальний час множенням. Виведи персоналізоване повідомлення.

Для `Nova`, `5`, `20` очікується:

```text
Nova, твій план: 100 хвилин підготовки.
```

Перевір випадок нульової кількості днів. Автоматичну перевірку коректності не додавай: вводь числа за умовою.

### 6. Код або число?

Прочитай код учасника через звичайний `input()` та виведи його разом із типом. Введи `0016`. Поясни, чому це поле не потрібно перетворювати на `int` і що втратиться після такого перетворення.

## Домашня робота — 20–30 хв

### Обов’язково: «Мій навчальний план» — 15–20 хв

Створи `homework03_plan.py`. Програма має отримати:

- псевдонім — текст;
- предмет або тему для вивчення — текст;
- вік у повних роках — ціле число;
- кількість навчальних днів — ціле число;
- час навчання на день у годинах — дробове число.

Потім обчислити в окремих змінних вік через рік і загальну кількість годин навчання. Використовуй `+` та `*`.

Виведи підсумок через f-рядки: привітання, тему, вік через рік і загальний час. Додай коментарі перед введенням та перед обчисленнями. Дані мають змінюватися під час запуску без редагування коду.

Приклад діалогу:

```text
Псевдонім: Nova
Тема навчання: Python
Вік цілим числом: 16
Кількість днів: 4
Годин на день, наприклад 0.5: 0.5

Привіт, Nova!
Тема навчання: Python
Через рік тобі буде 17 років.
Загальний час: 2.0 год
```

Для простоти використовуй підписи з одиницями, як у прикладі: не потрібно програмувати зміну закінчень слів.
