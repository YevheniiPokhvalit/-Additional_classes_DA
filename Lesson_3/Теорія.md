# Урок 3. Введення даних і перетворення типів

## 1. Від заготовлених значень до діалогу

На уроці 2 дані були записані в коді:

```python
nickname = "Pixel"
print("Привіт,", nickname)
```

Щоб змінити ім’я, доводилося редагувати програму. Тепер дозволимо користувачу ввести його під час запуску.

**Мета:** отримати текст через `input()`, перетворити числові дані через `int()` або `float()`, використати їх і вивести зрозумілу відповідь через f-рядок.

## 2. Функція `input()`

```python
nickname = input("Введи псевдонім: ")
print("Привіт,", nickname)
```

Під час виконання Python:

1. Показує підказку `Введи псевдонім: `.
2. Чекає, поки користувач введе відповідь і натисне Enter.
3. Повертає введений текст, який присвоюється змінній `nickname`.
4. Виконує наступний рядок.

Приклад діалогу:

```text
Введи псевдонім: Nova
Привіт, Nova
```

Тут `Nova` після підказки вводить користувач. У прикладах діалогів ми показуємо разом підказки, введені відповіді та вивід програми. Саме введення не потребує лапок.

### Як вводити у Thonny

Напиши код у редакторі → збережи → натисни F5 → дочекайся запитання у Shell → клацни після нього → введи відповідь → натисни Enter. Програма, що чекає введення, не зависла.

Пробіл наприкінці підказки потрібен для зручного вигляду діалогу. Сама підказка не стає частиною відповіді. Натискання Enter завершує введення; символ переходу на новий рядок `input()` у результат не включає.

## 3. `input()` завжди повертає рядок

```python
age_text = input("Скільки тобі років? ")
print(age_text)
print(type(age_text))
```

При введенні `16`:

```text
Скільки тобі років? 16
16
<class 'str'>
```

Вигляд значення ще не говорить про його тип. Навіть якщо введено цифри, результат `input()` — `str`.

## 4. Перетворення типів

### 4.1. Ціле число: `int()`

```python
age_text = input("Вік: ")
age = int(age_text)
print(type(age))
```

Для відповіді `16` останній рядок покаже `<class 'int'>`.

Це дві окремі дії: отримати текст і перетворити його. Коли цей порядок зрозумілий, можна записати коротше:

```python
age = int(input("Вік: "))
```

Читаємо **зсередини назовні**: спочатку `input()`, потім `int()`, потім присвоєння.

### 4.2. Дробове число: `float()`

```python
distance = float(input("Відстань у км, наприклад 2.5: "))
print("Відстань:", distance)
print(type(distance))
```

Введи `2.5`, використовуючи крапку. Результат матиме тип `float`. Введення `2` теж припустиме: отримаємо `2.0`.

| Потрібні дані | Як отримати | Приклад відповіді |
|---|---|---|
| Псевдонім | `input("Псевдонім: ")` | `Nova` |
| Ціла кількість | `int(input("Кількість: "))` | `4` |
| Дробове значення | `float(input("Відстань: "))` | `2.5` |

Не все, що складається з цифр, треба перетворювати на число. Наприклад, код учасника `0016` варто залишити текстом, якщо його не потрібно обчислювати: перетворення на `int` прибере початкові нулі.

## 5. Мінімум обчислень для сьогодні

Для вправ цього уроку достатньо двох операцій:

- `+` додає числа: `16 + 1` дає `17`.
- `*` множить числа: `3 * 20` дає `60`.

Результат теж можна зберегти у змінній:

```python
age = int(input("Вік: "))
next_age = age + 1
print("Через рік тобі буде", next_age)
```

Для введення `16` результат — `Через рік тобі буде 17`. Повний набір арифметичних операцій, порядок дій та округлення розглянемо на уроці 4.

### Додавання чисел і з’єднання тексту

```python
print("16" + "1")
print(16 + 1)
```

```text
161
17
```

Для двох рядків `+` означає з’єднання без автоматичного пробілу. Для двох чисел — додавання.

Ось **помилковий** приклад, який слід перевіряти окремо:

```python
age = input("Вік: ")
print(age + 1)
```

Виникне `TypeError`: не можна так додати рядок і ціле число. Потрібно перетворити введення через `int()`, а не додавати лапки навколо `1`: лапки змінили б сенс на з’єднання тексту.

## 6. Зручне виведення: f-рядки

Можна виводити через кому, як раніше:

```python
print("Привіт,", nickname)
```

Для точного оформлення зручно використати **f-рядок**:

```python
nickname = "Nova"
age = 16
print(f"Привіт, {nickname}! Тобі {age} років.")
```

```text
Привіт, Nova! Тобі 16 років.
```

- `f` стоїть **перед** відкривальними лапками.
- Усередині `{}` записуємо ім’я змінної, значення якої треба підставити.
- Пробіли та розділові знаки пишемо в самому рядку.
- Число можна підставляти без ручного перетворення на текст.

Без `f` підстановки не буде: `print("Привіт, {nickname}!")` виведе фігурні дужки та слово `nickname` буквально.

## 7. Розібраний приклад: інтерактивна анкета

Відкрий [Приклади/01_questionnaire.py](Приклади/01_questionnaire.py).

```python
# Отримуємо дані та перетворюємо вік на число.
nickname = input("Твій псевдонім: ")
age = int(input("Твій вік цілим числом: "))
hobby = input("Твоє захоплення: ")

# Обчислення відокремлено від введення та виведення.
next_age = age + 1

print()
print(f"Привіт, {nickname}!")
print(f"Твоє захоплення — {hobby}.")
print(f"Через рік тобі буде {next_age} років.")
```

Для відповідей `Nova`, `16`, `музика`:

```text
Твій псевдонім: Nova
Твій вік цілим числом: 16
Твоє захоплення: музика

Привіт, Nova!
Твоє захоплення — музика.
Через рік тобі буде 17 років.
```

Програма має три частини: **введення → обробка → виведення**. Зміни псевдонім і вік під час другого запуску, не редагуючи код.

## 8. Число з дробовою частиною в роботі

Порахуймо відстань двох прогулянок:

```python
first_distance = float(input("Перша відстань у км: "))
second_distance = float(input("Друга відстань у км: "))
total_distance = first_distance + second_distance
print(f"Разом: {total_distance} км")
```

Для `2.5` та `1.5` результат — `Разом: 4.0 км`. Закінчення `.0` нормальне: результат має тип `float`.

Деякі дроби зберігаються наближено: наприклад, `0.1 + 0.2` може показати `0.30000000000000004`. Це особливість зберігання чисел, а не помилка введення. Для основних вправ беремо прості значення; округлення вивчатимемо окремо.

## 9. Типові помилки

| Симптом | Причина | Що зробити зараз |
|---|---|---|
| Замість суми вийшло `1213` | З’єднали рядки `"12"` і `"13"`. | Перетворити кожне введене число через `int()`. |
| `TypeError` у `age + 1` | `age` залишився рядком. | Перетворити введення на число. |
| `ValueError` після введення `шістнадцять` | `int()` не може прочитати це як ціле число. | Запустити знову та ввести `16`. |
| `ValueError` після введення `16.5` для `int()` | Рядок не є записом цілого числа. | Для віку в цілих роках вводити ціле; для дробових даних використовувати `float()`. |
| `ValueError` після введення `2,5` для `float()` | У цьому форматі потрібна крапка. | Ввести `2.5`. |
| Видно `{nickname}` | Пропущено `f` перед лапками. | Написати `f"...{nickname}..."`. |
| Після підказки нічого не відбувається | Програма очікує відповідь. | Ввести її в Shell і натиснути Enter. |

Порожній рядок теж не можна перетворити на число цими викликами. Сьогодні ми розуміємо причину помилок і перезапускаємо програму. Автоматичну перевірку, повторне введення та `try` / `except` вивчатимемо пізніше.
